# 万象归鑫 · XinGraphX

**科研万象，一绘归鑫。**

从参考图或文字方案制作科研图：以忠实复刻模板为最高目标，文字与简单结构原生可编辑，具象小图和插画立即生图。

[English](README.en.md) · [快速开始](#快速开始) · [安装](#安装) · [技能文件](skills/xingraphx/SKILL.md) · [MIT License](LICENSE)

万象归鑫（XinGraphX）是面向 AI Agent 的通用科研绘图 skill，支持科研示意图、方法流程、机制图和技术路线。它将内容核对、布局规划、可编辑重建与渲染验收组织成可复用工作流，默认交付单页 **PPTX + 高清 PNG**。

## 核心能力

| 输入或需求 | 工作方式 | 交付要求 |
| --- | --- | --- |
| 参考图复刻 | 严格还原模板布局、背景、配色、间距、层级和视觉关系 | 发现问题先指出，不擅自美化或修改 |
| 文字方案绘图 | 组织信息层级与阅读顺序，按内容确定画布 | 清晰分区、有限配色、紧凑布局 |
| 可编辑重建 | 用原生 PPT 对象构建文字、连接箭头、节点框、数据图、坐标轴和曲线 | 支持对象级修改；节点内图标单独处理 |
| 数学公式 | 使用 PowerPoint 原生 Office Math | 保留分式、上下标等结构 |
| 插画与图标 | 无论多简单，具象小图和插画均立即生成独立透明素材 | 可移动、可替换；文字和连接线单独编辑 |
| 交付验收 | 检查保存后的文件结构与真实渲染 | PNG 长边至少 3600 像素 |

这些是技能规定的制作与验收要求，实际完成情况取决于 Agent 的工具、字体与渲染环境；交付时应记录实际验证结果。

## 小图立即生图，结构原生可编辑

设备、太阳、电池外观、人物、器官等具象小图与插画，无论看起来多简单，都立即调用生图模型，不按难度决定是否生图，也不先用 PPT 形状、SVG 或程序绘图试拼。文字、Office Math 公式、数据图、坐标曲线、标准科学符号、抽象节点和点线面箭头保持原生可编辑。例如，电池的标准电路符号可以原生绘制，电池外观小图直接生图；纯抽象流程无需生图。

自动调用生图，无需逐项确认。以模板对应区域指导单个素材重绘，保留轮廓、视角、比例、配色和关键细节，默认透明、无文字，作为独立图片放入 PPT。图片可移动与替换，内部细节不能逐对象编辑；文字标注、节点框和连接线单独构建。不将整页、整个流程或大块面板转成图片，不直接裁切原图充当重绘；局部裁图仅可作为生图参考输入。

每个素材首次生成后最多追加三轮针对性修正，总计最多四次生成，达标即停止。每轮记录明确差异并修正；仍明显不符或工具不可用时，保留最佳候选，继续其他工作，集中列出差异请用户决定，不退回形状拼画，也不判为通过。用户明确要求全部原生可编辑时遵循该要求，遇到冲突集中说明并确认取舍。

## 忠实复刻模板

参考图任务以完美复刻用户模板为最高目标，严格还原布局、背景、位置、比例、间距、层级和配色，不擅自美化、换风格或改变结构。发现错字、遮挡或科学含义问题时先指出，由用户决定是否修改；无模板的文字绘图任务继续按内容组织清晰布局。

以最终 PPT 渲染与模板并排对照，必要时叠加检查。先检查整图，再逐个放大小图核对轮廓、视角、比例、配色、透明边缘、关键细节和科学结构。记录实际差异，不能仅凭生成或导出成功就宣称已完美复刻。

## 连续文字整段编辑

同一段落、列表或同一节点内的连续多行说明默认使用一个原生文本框，不再一行一个框。字号、粗细和颜色变化用框内局部格式处理；少量行内异字体也保留同框，独立成段或成块的异字体文字另起框。

不同节点、面板、分栏及独立定位区域不跨区合并；标题、图题、坐标刻度、图例项和独立标注保持独立。通过段落、行距、缩进和文本框尺寸排版，检查合并后的换行、溢出与对齐，不用多个框分组冒充整段编辑。原生公式要求保持不变。

## 演讲 PPT 的逐页讲稿

任务包含演讲、授课、答辩或汇报类 PPT 时，自动在每页原生备注中写入可直接讲的完整口语稿，并以“建议用时”开头。讲稿解释本页要点和图表，衔接前后页；封面、目录和过渡页也有对应内容，核心图表与结论页按重点展开。

未提供演讲时长时先询问，收到后再完成讲稿。默认时长指纯演讲时间；明确包含问答时先扣除问答，再留约 10% 给停顿和切页。中文按每分钟约 220 字估算，技术密集内容适当放慢，各页按重要性和难度分配，避免平均分配或凑字数。估算不保证实际现场时长。

修改已有 PPT 时保留仍适用的讲稿，按新页面和时长调整。来源和示意数据声明独立保留，不计入口播篇幅。交付前检查保存后的逐页备注、页序、完整性和时间预算。单张科研图沿用原有规则；明确仅处理图形或不写讲稿的要求优先。

## 快速开始

安装后，将参考图或文字方案交给 Agent，并明确使用 `xingraphx`：

```text
使用 xingraphx，根据这张参考图重建科研示意图。
保留面板结构、配色和箭头关系，文字、公式、节点框与曲线采用原生可编辑对象。
具象小图和插画立即生图，独立放置，不先用形状试画；文字标注和连接线单独编辑。
严格沿用模板背景、布局、比例和配色，不擅自美化；对照最终 PPT 渲染检查实际差异。
交付单页 PPTX 和高清 PNG，并完成结构与渲染检查。
```

```text
使用 xingraphx，将以下研究方案绘制为技术路线图：
数据采集 → 数据清洗 → 特征提取 → 模型训练 → 评估与解释。
采用白底、紧凑布局和清晰分区，交付可编辑 PPTX 与高清 PNG。
```

```text
使用 xingraphx，重建附件中的公式、坐标轴与趋势曲线。
公式使用 Office Math；没有原始数据的曲线标注为示意图。
```

演讲用途可这样说明：

```text
使用 xingraphx，完善这套用于学术汇报的 PPT，总演讲时间 20 分钟，问答另计。
在每页备注中写入可以直接讲的完整稿，标注建议用时，按内容难度分配篇幅。
保留已有来源和示意声明，并检查保存后的逐页备注。
```

## 安装

克隆本仓库：

```bash
git clone https://github.com/X-laboratory-678/xingraphx.git
```

将 `skills/xingraphx/` **整个文件夹**复制到所用 Agent 的技能目录。保留 `agents/` 和 `references/`，不能只复制 `SKILL.md`。如果使用自定义 profile，请以该 profile 实际的技能目录为准。

也可以将下面的提示词和仓库链接交给支持本地文件操作的 Agent：

```text
请从 https://github.com/X-laboratory-678/xingraphx 安装 xingraphx skill。
先检查当前环境的技能目录，再复制完整的 skills/xingraphx 文件夹。
如果已有同名技能，先比较差异并保留本地修改。
```

不安装时，也可让 Agent 读取本地克隆中的 `skills/xingraphx/SKILL.md`，并按需读取其引用文件。

## 环境与输出

本项目提供技能指令和验收规范，使用时需要能够读取附件、生成和修改 PPTX、渲染 PPTX 及导出 PNG 的 Agent 环境。所有具象小图与插画都需要生图能力；纯几何流程和标准科学符号等任务无需生图。

若环境提供 `presentations` 或 `imagegen` skill，XinGraphX 会按任务需要调用对应能力。它们不随本仓库分发；`load_workspace_dependencies` 等工具也仅在宿主环境提供时可用。

- 每张独立图默认交付一份单页 PPTX 和一张 PNG；同图多个面板放在同页。
- 画布优先遵循指定尺寸；参考图沿用原图宽高比；文字方案按内容布局。
- PNG 在参考图任务中保留模板背景与配色，无模板文字入口默认白底；长边至少 3600 像素，指定物理尺寸时同时满足 300 dpi 像素要求。
- 保留实际构建脚本、素材及检查记录，记录原生与生图分工、参考区域、每轮差异与修正次数、最终尺寸检查结果、经确认的内容修正和实际限制；交付时区分原生对象与图片。
- 优先使用 PowerPoint 渲染；其他渲染器需注明实际工具及未验证项。

## 科学内容与编辑边界

不编造实验数据、公式依据、因果关系或科学结论。无原始数据的示意曲线应在 PPT 备注和交付说明中注明“示意图，无原始实验数据”。复杂插画作为独立图片交付；三维轨迹默认重建为可编辑二维投影，不具备可旋转三维能力。

本技能不包含合入既有图集、插入 Word 或文档排版；这些可作为独立任务处理。
