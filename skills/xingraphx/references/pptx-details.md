# 原生公式和分组缩放实现注意事项

仅在需要编辑 OOXML 或调试数学排版、缩放异常时使用。按当前工具实现选择方案，不把某个 XML 写法视为跨工具保证。

## 原生公式

- 使用合法的 Office Math / OMML 结构及 PowerPoint 所需包装和命名空间，保留上下标、分数等数学结构。普通文本拼接或 SVG 公式不满足原生公式要求。
- 数学默认样式可能使数字、英文下标保持正体；仅设置 m:sty 为 i 不一定使所有字符实际斜体。
- 在需要时，对数学字母数字运行设置显式斜体字体属性（例如 a:rPr i="1"），使用真正支持斜体的字体；结合 m:rPr 的 m:nor 与 m:sty 检查其实际显示。先验证样例，不能不看渲染就批量宣称成功。
- 混合中文与数学字符时拆分运行，避免中文随数学字母一起倾斜；符号不强制改变为字母数字样式。
- 修改时遵守 XML 元素顺序及命名空间，防止错误前缀或不合法结构导致修复提示或公式丢失。重新打开最终 PPTX 并检查，保留渲染证据。

## 分组与缩放

- 手写组变换可缩放几何位置和尺寸，却未必同步缩放显式字号和线宽。检查 a:xfrm 的 off/ext/chOff/chExt 与子对象样式。
- 需要同步调整时，核对文本字号、字距、段落点距和线宽；若工具已自动缩放，避免再次乘比例导致双重缩放。默认保持等比几何，避免公式和文字拉伸。
- 对象名称不是类型，也未必唯一。修改文字框前确认实际具有文本或数学内容；修改曲线前确认路径类型。
- 维护有效的对象 ID、媒体关系与图片资源引用。结构检查和预览检查都通过后才视为修复完成。
